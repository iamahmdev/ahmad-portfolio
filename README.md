# Ahmad Iqbal – 3D Portfolio (Next.js)
    npm install
    npm run dev    # http://localhost:3000

Optional live AI agent: copy `.env.example` to `.env.local` and set ANTHROPIC_API_KEY. Without it the agent uses a built-in fallback.


Contact form: set RESEND_API_KEY (email) and/or CALLMEBOT_APIKEY (WhatsApp) so "Send message" delivers to you. The WhatsApp and Email buttons work without any keys.
